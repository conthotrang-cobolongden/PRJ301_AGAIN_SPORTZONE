# Phase 2 Auth & Authorization Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver Phase 2 login, registration, logout, authenticated-route protection, and Admin authorization for A1, A2, U1, U2, and U3.

**Architecture:** Keep the existing Servlet/JSP MVC foundation. `AccountDAO` owns SQL, `AuthService` owns normalization and authentication/registration rules, servlets own HTTP/CSRF/session behavior, and filters enforce authentication before role authorization. Reuse the existing `Account`, `SessionUtil`, `CsrfUtil`, `Validation`, `AppConstants`, `Views`, and JSP layout contracts.

**Tech Stack:** Java 8, Tomcat 9, `javax.servlet`, JSP/JSTL 1.2, JDBC/SQL Server, NetBeans Ant WAR, main-method contract tests.

**Design spec:** `docs/superpowers/specs/2026-08-19-phase-2-auth-design.md`

```java
        String phone = "039" + suffix.substring(suffix.length() - 7);
        int accountID = 0;
        try {
            Account input = new Account();
            input.setRoleID(2);
            input.setEmail(email);
            input.setPhone(phone);
            input.setPasswordHash("3e7c19576488862816f13b512cacf3e4ba97dd97243ea0bd6a2ad1642d86ba72");

            LocalDateTime before = created.getLastLoginAt();
            dao.updateLastLogin(accountID);
            LocalDateTime after = dao.findById(accountID).getLastLoginAt();
            require(after != null && (before == null || !after.isBefore(before)),
                    "LastLoginAt must be updated");
        } finally {
            if (accountID != 0) deleteAccount(accountID);
        }
        System.out.println("AccountDAOContractTest PASSED");
    }

    private static void deleteAccount(int accountID) throws Exception {
        try (Connection connection = DBUtils.getConnection();
             PreparedStatement statement = connection.prepareStatement(
                     "DELETE FROM Accounts WHERE AccountID = ? AND Email LIKE 'phase2-%@sportzone.local'")) {
            statement.setInt(1, accountID);
            statement.executeUpdate();
        }
    }

    private static void require(boolean condition, String message) {
        if (!condition) throw new AssertionError(message);
    }
}
```

```java
public static final class RegisterResult {
    private final Map<String, String> fieldErrors;
    private final Account account;

    private RegisterResult(Map<String, String> fieldErrors, Account account) {
        this.fieldErrors = Collections.unmodifiableMap(new LinkedHashMap<>(fieldErrors));
        this.account = account;
    }

    public boolean isSuccess() { return account != null && fieldErrors.isEmpty(); }
    public Map<String, String> getFieldErrors() { return fieldErrors; }
    public Account getAccount() { return account; }
}
```

```java
private String consumeTarget(HttpSession session) {

    session.removeAttribute(AppConstants.SESSION_REDIRECT_AFTER_LOGIN);
    if (value instanceof String && ((String) value).startsWith("/")) {
        return (String) value;
    }
    return "/home";
}
```
